# ApexGuard Technologies — SaaS GRC Security Assessment

## Project Overview

This project simulates the responsibilities of a GRC Analyst supporting a B2B SaaS organization during an enterprise customer security and compliance assessment.

ApexGuard Technologies is a fictional SaaS company providing insurance and risk-management technology. A prospective financial-services customer, Meridian Financial Group, is conducting third-party security due diligence before onboarding the platform.

As the assigned GRC Analyst, I am responsible for evaluating security questionnaire responses, validating control claims against evidence, identifying security and compliance risks, documenting findings, coordinating remediation, and providing a final risk recommendation.

## Objectives

- Perform an evidence-based security and compliance assessment
- Review and validate customer security questionnaire responses
- Evaluate control design and operating effectiveness
- Identify and document security risks
- Maintain a risk register
- Identify control deficiencies and remediation requirements
- Map controls to relevant security and compliance frameworks
- Evaluate remediation evidence
- Provide an executive-level risk recommendation

## Frameworks & Standards

This project incorporates concepts from:

- NIST Cybersecurity Framework (CSF) 2.0
- ISO/IEC 27001
- SOC 2 Trust Services Criteria
- Enterprise risk management practices
- Third-Party Risk Management (TPRM)

## Portfolio Deliverables

The completed project will include:

- Risk Register
- Security Questionnaire Review
- Evidence Request List
- Control Testing Workbook
- Control Mapping Spreadsheet
- Findings & Remediation Tracker
- Executive Risk Summary

## Skills Demonstrated

Risk Assessment | Control Testing | Evidence Review | Customer Assurance | SOC 2 | ISO 27001 | NIST CSF | TPRM | Risk Remediation | Security Compliance
